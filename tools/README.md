# نسخ الرجوع المحلية (بدون GitHub ولا إبديت)

هذا المجلد فيه أداة صغيرة تحفظ لك "نقاط رجوع" لكل تعديل، وتخليك ترجع لأي تعديل سابق بأمان.
كله محلي على جهازك: مافي ريموت، مافي رفع للسحابة، وماله علاقة بتحديث التطبيق.

## الاستخدام

من داخل مجلد المشروع (`music app`):

```
tools\snap.bat save "شنو سويت في هذا التعديل"
tools\snap.bat list
tools\snap.bat diff
tools\snap.bat show 3
tools\snap.bat back 3
```

| الأمر | وظيفته |
| --- | --- |
| `save "الوصف"` | يحفظ كل تعديلاتك الحالية كنقطة رجوع |
| `list` | يعرض آخر النقاط (`#1` = الأحدث) |
| `diff` | يعرض التعديلات غير المحفوظة الآن |
| `show 3` | يعرض ملخص ما تغير في النقطة رقم 3 |
| `back 3` | يرجّع المشروع كامل لحالة النقطة رقم 3 |
| `status` | حالة الملفات باختصار |

## قواعد مهمة

- احفظ نقطة قبل أي تعديل كبير، وبعد أي بناء ناجح.
- `back` يحفظ شغلك الحالي أولاً كنقطة منفصلة، ويطبع لك أمر الرجوع عنه — يعني ما يضيع شيء.
- أرقام النقاط تتغير بعد كل حفظ أو رجوع، فاستخدم `list` قبل `back`.
- الملفات المؤقتة والمبنية (`build/`، `.apk`، مفاتيح التوقيع، `local.properties`) مستثناة أصلاً من التتبع.
- لا تضف ريموت لهذا المستودع (`git remote add ...`) إذا ما تبيه وسيلة تحديث.

## ملاحظة عن بناء APK

الأداة للرجوع فقط. تحديث التطبيق على الجوال يبقى يدوي:

```
sukoon-nocturne\..\gradle assembleDebug   (أو من Android Studio)
adb install -r app-debug.apk
```
